# 034.5 — Existing Cell continuation management

**Status:** Plan
**Parent:** [034 — Multi-source cell continuations](034-multi-source-cell-continuations.md)
**Depends on:** 034.3 and shared UI from 034.4
**Scope:** Add, reorder, and detach continuation sources from an existing Cell.

## Current behavior

`frontend/src/components/CellDetailTabs.tsx::FilesPanel` renders a table per Test with filename,
path, row/cycle counts, source/parse state, hash, and an Update button. It cannot mutate source
membership or show which source scheduled monitoring tracks.

## Target Files panel

For each Test:

- render the shared `ContinuationSourceList`;
- show stable ordered position, filename/path, local cycles, detected time range, parse/source
  status, and hash prefix;
- label all non-final Cell sources `Historical source`;
- label the final source of the final non-empty Test `Tracked tail`;
- retain per-source Update behavior for explicit manual source adoption;
- add **Add continuation**, **Reorder**, and **Detach** actions subject to backend permissions.

### Add continuation

Use the extracted `ImportFilesystemPickerModal` from 034.4, then the same inspection/findings/source
list UI. Default to appending to the final Test. If the user selects another Test, explain whether
the resulting source is or is not the Cell-wide tracked tail. Submission calls the single atomic
034.3 endpoint.

### Reorder

Allow drag and keyboard Move up/down within one Test only. Show the proposed old/new tracked tail
and compatibility findings before saving. Do not permit cross-Test dragging in this child.

### Detach

Open a confirmation using the source-change impact response. It must name the source, explain that
global cycle numbering and saved analyses may change, list affected analysis/plot counts, and say
that the original file on disk is not deleted. Disable detach when it would leave the Test empty.

## Cache and query behavior

After a successful mutation:

- replace/invalidate the Cell detail;
- invalidate Cell list, Projects tree/metrics, source status, analyses, saved-plot/activity, and
  background-job queries affected by the API response;
- do not optimistically invent new cycle totals or parse status;
- show queued parsing/invalidation activity through existing global activity UI;
- if the currently open Cell detail closes/reopens, order and tracked-tail labels remain identical.

Avoid duplicated toasts caused by both mutation callbacks and global job completion.

## Files expected to change

- `frontend/src/components/CellDetailTabs.tsx`
- `frontend/src/components/ContinuationSourceList.tsx`
- `frontend/src/components/ImportFilesystemPickerModal.tsx` only for reusable props, not redesign
- `frontend/src/api.ts`
- the Cell-detail owner in `frontend/src/pages/LibraryPage.tsx` if mutation callbacks/query
  invalidation live there
- `frontend/tests/continuationPolicy.test.ts`
- a focused `frontend/tests/continuationManagement.test.ts` (new) if needed

## Acceptance

- The exact source order and tracked tail are understandable without opening metadata.
- Add/reorder/detach use one atomic backend mutation each.
- Cell metadata never changes after adding a continuation.
- Reorder remains within one Test and requires review of changed findings/tail.
- Detach cannot empty a Test and clearly states disk data is preserved.
- All affected views refetch; no stale source count/order remains.
- Long filenames do not create horizontal layout overflow.
- Keyboard-only operation and dark mode remain usable.
