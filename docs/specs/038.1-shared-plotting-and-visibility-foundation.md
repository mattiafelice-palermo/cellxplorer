## Goal

Create the stable foundation required by every later child:

1. give all existing shared plot presentation/style modules their final home;
2. extract common plot header, layout, export, and runtime code from `AnalysisPage.tsx`;
3. update every existing family card to import those helpers from the plotting folder instead of
   importing from the page that imports the card;
4. make the context-aware visibility policy the single owner of cell, segment, and series hiding.

This child intentionally leaves Cycles, Time/Capacity, saved previews, portable flow, and the main
editor controller inside `AnalysisPage.tsx`. It removes the family-card circular dependency before
those larger extractions begin.

### Duplicate visibility policy

`frontend/src/analysisVisibility.ts` currently exports:

- `CellSelectionContext`;
- context-aware `isCellHiddenInAnalysis(spec, cellId, contexts?)`.

Its rule is important: when a cell appears through several direct/group selection contexts, the
shared cell series is hidden only if all relevant contexts are hidden. When contexts are omitted,
it preserves the older any-exclusion behavior.

`AnalysisPage.tsx` separately exports a simpler two-argument `isCellHiddenInAnalysis`, plus
segment/series helpers. Rate Capability imports the context-aware root module; the other three
standalone families import the simpler page helpers. This split must end.

## Unified visibility contract

`features/analyses/editor/policies/analysisVisibility.ts` must export:

```ts
export interface CellSelectionContext {
  cell_id: number
  entry_kind: SelectionEntry["kind"]
  entry_ref_id: number
}

export function isCellHiddenInAnalysis(
  spec: AnalysisSpec,
  cellId: number,
  contexts?: readonly CellSelectionContext[],
): boolean

export function isAnalysisSegmentHidden(spec: AnalysisSpec, segmentId: string): boolean
export function isSeriesHidden(spec: AnalysisSpec, seriesId: string): boolean
```

Locked semantics:

- a global cell exclusion hides the cell;
- with supplied context metadata, a shared cell series is hidden only when all of that cell's
  relevant contexts are hidden through exact exclusions and/or hidden replicate groups;
- with `contexts === undefined`, preserve the current legacy fallback: any exclusion for that cell
  hides its family series;
- no matching context means visible, not hidden;
- segment and series helpers are display-only reads of
  `presentation.hidden_analysis_segment_ids` and `presentation.hidden_series_ids`;
- these helpers never mutate the spec and never remove cells from backend calculation requests.

Update Steps, DCIR, Chargeability, Rate Capability, and the remaining code in `AnalysisPage.tsx` to
use this one module. Delete the three page-owned visibility exports.

Extend `frontend/tests/analysisVisibility.test.ts` to cover:

- global exclusion;
- one of two contexts excluded while the other remains visible;
- all contexts excluded;
- hidden replicate-group context combined with a visible direct context;
- no contexts supplied (legacy fallback);
- no context for the requested cell;
- segment and series hidden/present/absent lists.

  imports consistent with the repository.
