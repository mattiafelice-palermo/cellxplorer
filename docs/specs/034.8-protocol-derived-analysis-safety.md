# 034.8 — Protocol-derived analysis safety for continued Cells

**Status:** Plan
**Parent:** [034 — Multi-source cell continuations](034-multi-source-cell-continuations.md)
**Depends on:** 034.3
**Scope:** Fail-closed guard for Steps, DCIR, Chargeability, and Rate capability.

## Scientific risk

Restarted protocols frequently renumber steps. A charge step displayed as step 20 in the original
file may be step 11 in the continuation. Current code has partial source-awareness:

- Steps/DCIR can use source protocol signatures and segment data.
- `chargeability.py` and `rate_capability.py` iterate ordered source hashes and report source hashes.

That is not yet a reviewed cross-source semantic mapping. Allowing these tabs to compute can mix,
omit, or relabel source-local steps while looking scientifically valid.

## One central support decision

Create one backend helper that resolves the analysis selection and returns Cells containing more
than one ordered `SourceFile`. All protocol-derived endpoints and background job creation must call
it:

- `/api/analyses/{id}/steps`
- `/api/analyses/{id}/dcir-protocols`
- `/api/analyses/{id}/dcir`
- `/api/analyses/{id}/chargeability`
- `/api/analyses/{id}/rate-capability`
- `/api/analyses/{id}/compute-jobs` for those kinds
- any saved-plot warmup/portable recompute path that calls these services

Do not copy count logic into four services.

## Fail-closed response

If any Cell targeted by the requested plot contains multiple ordered sources:

- perform no protocol recognition/computation for any Cell in that request;
- do not open a background job;
- do not return cached scientific series, even if a pre-merge key happens to exist;
- return a structured 422 response:

```json
{
  "code": "multi_source_protocol_mapping_required",
  "plot_family": "rate_capability",
  "unsupported_cells": [{"id": 1, "name": "Cell A", "source_count": 2}],
  "supported_alternatives": ["cycles", "time_capacity"],
  "message": "This plot uses source-local protocol steps..."
}
```

Failing the whole request prevents a mixed selection from silently plotting only the single-source
Cells.

Single-source Cells remain fully supported and unchanged.

## Frontend behavior

Before enabling a protocol-derived query, derive the same condition from typed Cell/analysis
selection data where available. Backend remains authoritative.

For a guarded selection:

- show a calm inline explanatory state in the plot area, not a spinner/error toaster;
- name affected Cells (truncate with a count/popover for long lists);
- explain that restarted files can renumber steps and CellXplorer refuses to guess;
- link/suggest Cycles and Time / capacity;
- disable Save and scientific export for the unsupported draft;
- existing saved plots show the same unsupported state instead of old thumbnails/data;
- do not start recognition progress polling;
- warmup/background activity does not enqueue the plot.

Use the visual style guide’s informational/warning surfaces. This is a scientific limitation, not
a destructive red application error.

## Future-proof identity

Document but do not implement the future mapping key:

```text
(source protocol signature, source-local step index) -> semantic operation
```

Do not normalize solely by numeric ID, step type, or C-rate. A future spec may allow user-reviewed
semantic mappings and then relax this guard per family.

## Files expected to change

- `backend/app/services/analysis_engine.py` or a small dedicated support-policy service
- `backend/app/routers/analyses.py`
- `backend/app/services/warmup.py` and portable dispatch only where they can bypass the router
- `frontend/src/pages/AnalysisPage.tsx`
- tab-specific cards such as `ChargeabilityPlotCard.tsx` and `RateCapabilityPlotCard.tsx` only as
  needed
- `frontend/src/api.ts`
- a pure `frontend/src/multiSourceAnalysisPolicy.ts` (new)
- backend analysis/service tests for all four families
- `frontend/tests/analysisPlotPolicy.test.ts` or a focused new policy test
- chargeability/rate-capability agent knowledge

## Acceptance

- No guarded endpoint computes, caches, queues, or returns protocol-derived data for a selection
  containing any multi-source Cell.
- Mixed selections fail as a whole.
- Single-source behavior and recognition progress remain unchanged.
- Existing saved plots cannot display stale pre-guard scientific output.
- UI clearly explains why Cycles/Time work and these families do not.
- There is one support predicate per backend and one pure mirrored presentation predicate in the
  frontend, not four divergent implementations.
