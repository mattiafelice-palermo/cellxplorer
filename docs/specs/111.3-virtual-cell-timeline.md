# 111.3 — Join-aware timeline and preview

**Status:** Planned implementation step 3 of 7. [Parent contract](111-virtual-cells.md). Depends on [111.2](111.2-virtual-cell-lifecycle.md).

Build the read path shared by the combine preview and Time / capacity. Reuse the existing continued-cell preview surface and plotting machinery.

- Assemble the proposed or persisted run order through the same resolver. Keep trace provenance through sampling, zoom, point inspection and export: virtual subject, physical run, source, source-local record and cycle, and displayed cycle where available.
- Preserve existing in-run chronology, current/voltage trust, acquisition breaks and source-local clocks. Use the actual first/last measurements to suggest ordering. Identify the wall-clock gap separately from elapsed recording time. Show unknown or overlapping times explicitly and let the user confirm the order. Show each join on the plot and break the drawn line across an unmeasured interruption.
- For **Cycling resumed**, apply existing continuation and pairing rules only when their evidence permits. For **Electrode or setup changed**, break phase, half-cycle and capacity transforms at the join. Keep an unmatched half and any leading rest visible. Use the programmed-cycle view by default, and respect discharge-first pairing in both preview and saved plots.
- Keep existing time units and cycle-aligned versus continuous display. Preview individual runs or all combined, using bounded reads and downsampling. Key preparation and cached coordinates by run order, source identities, interpretation and joins. A different join on the same files must miss the incompatible cache.

**Acceptance.** Use a measured discharge in A followed by a charge in B. A resumed join can pair when supported. A replacement join always separates them. Check time zero, days, a known overnight gap, unknown times, full versus zoomed data, stacked current, click-through provenance and preview/plot agreement. A voltage-only run contributes its usable trace without supplying a cycle or current value.
