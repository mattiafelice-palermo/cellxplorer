# 111.4 — Cycles and scientific references

**Status:** Planned implementation step 4 of 7. [Parent contract](111-virtual-cells.md). Depends on [111.3](111.3-virtual-cell-timeline.md).

Produce Cycles and recap values from the same join-aware assignment as the timeline.

- Keep a global display cycle index and the run/source-local identities. Preserve actual measured charge and discharge increments. Count only completed cycles for summaries. Never pool unmatched halves across a replacement. Handle a continued cycle spanning a supported resume boundary and a physical run that already contains several sources.
- Resolve mass, electrode area and nominal capacity from the physical run’s applicable settings, including existing user overrides and converted source units. Compute directional specific capacity using the reference for the measurements that produced it. If one derived value would require a common denominator across runs and that denominator is missing or inconsistent, mark the affected value unavailable and explain why. Preserve absolute measurements and independently valid quantities.
- At a replacement, start a new retention/formation baseline and equivalent-full-cycle reference segment. Retain a continuous global cycle number for navigation. Keep experiment-wide **absolute** cumulative throughput distinguishable from run-specific normalized metrics. Never sum percentages or average already-normalized discharge and charge to invent a cross-join value.
- Apply the same conventions in summaries, point inspection, filters, exports and saved-plot previews. Show which run supplies a reference. Partial data and absent metadata retain their ordinary scientific limitations.

**Acceptance.** Use different known masses, areas and nominal capacities for A and B, plus a missing-reference variant. Check mAh against raw records, mAh/g against each run’s denominator, no efficiency across replacement, retention and FEC reset, absolute throughput, and agreement between areas of the UI at the boundary. Plotting either original alone must reproduce its pre-combine result.
