- extract the Analysis Database workflow from the route file into `AnalysesIndexView.tsx`;

## Route/view boundary

### `pages/AnalysesIndexPage.tsx`

The route file must contain only:

- `useNavigate`/`useSearchParams` or equivalent router adaptation;
- translation of the three current search intents:
  - `new=1`;
  - `portableImport=1`;
  - `portableSource=<local source path>`;
- callbacks that remove consumed parameters with `{ replace: true }`;
- navigation callback(s) for opening an analysis;
- rendering `<AnalysesIndexView ... />`.

It must not own React Query calls, create/delete/import mutations, Analysis Database table state, or
modal content.

### `database/AnalysesIndexView.tsx`

The view owns the complete collection workflow now inside `AnalysesIndexPage`, including the local
helper components. Use a small explicit route contract rather than passing router objects deeply.
The exact TypeScript spelling may follow current repository types, but it must express these
values/callbacks:

```ts
type AnalysesIndexRouteIntent = {
  openCreate: boolean
  openPortableImport: boolean
  portableSource: string | null
}

type AnalysesIndexViewProps = {
  routeIntent: AnalysesIndexRouteIntent
  consumeRouteKeys: (keys: Array<"new" | "portableImport" | "portableSource">) => void
  navigateToAnalysis: (analysisId: number) => void
}
```

Equivalent names are acceptable. The locked behavior is not:

- intents remain reactive if search parameters change while the page is mounted;
- `new=1` opens the create modal once and is then consumed;
- `portableImport=1` opens the portable import modal;
- `portableSource` is inspected once per distinct source and is consumed/reset through the current
  workflow;
- closing/cancelling a staged portable import still discards its backend token when required;
- successful create/import still navigates to the resulting analysis;
- URL cleanup uses replacement, not a new history entry.

Do not make the view accept raw `URLSearchParams`, `NavigateFunction`, or a page component. Keep the
feature independently understandable and the route adapter small.
