## Closure principle: canonical format neutrality

Correct final architecture:

```text
.mpr
  ↓
independent BioLogic reader + GCPL adapter
  ↓
canonical raw/protocol/capabilities
  ↓
source-specific parser cache/provenance
  ↓
existing CellXplorer scientific services
```

Wrong closure pattern:

```python
if source.ext == ".mpr":
    calculate_capacity_or_dcir_differently()
```

Search and reject BioLogic extension/format branches inside `calc.py`, DCIR, Chargeability, Rate Capability, Steps and generic analysis computations unless the branch is strictly about source metadata/provenance/capability presentation.
