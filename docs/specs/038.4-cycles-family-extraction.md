## Goal

Extract the complete Cycles frontend adapter from `AnalysisPage.tsx` into:

```text

```

The file must own the Cycles settings, optional shared query hook, quantity resolution, diagnostic
display filtering, cycle trace/layout construction, live plot, style preview, and ordinary family
exports. The already-moved `diagnosticCycles.ts` remains beside it.

One Cycles point represents one completed cycle. The backend continues to decide every per-cycle
value, retention reference, aggregate input, source mapping, and provenance. This child changes
ownership only.

## Target public surface

The exact internal names may follow the current code, but the family file must export a clear,

```ts
export type UseCyclesResultArgs = {
```

Equivalent names are acceptable if every consumer imports directly from this file and generic
names such as `tracesForResult` do not leak into unrelated families. `CyclePlotCard` retains the
current props unless extracting the query hook removes a now-redundant value; do not redesign its
parent callback contract.

Private helpers should remain private. Do not create separate `model.ts`, `query.ts`, `traces.ts`,
or `layout.ts` files in this child merely to reduce line count. The locked target is one cohesive
family file plus `diagnosticCycles.ts`.

## Query contract

If `useCyclesResult` is extracted, preserve:

- query key `['compute', analysisId, computeSignature(spec)]` exactly;
- endpoint and payload, including `job_token`;
- cache-miss progress-token behavior and delayed clearing;
- `staleTime: 5 * 60_000`;
- enablement only when the spec exists, initial shell readiness is true, and the active family uses
  the generic cycle engine;
- no generic compute request while Time/Capacity, Steps, DCIR, Chargeability, or Rate Capability is
  active;
- background job polling key/endpoint/interval and terminal behavior;
- last valid rendered result while a refresh is pending;
- initial-ready gating that lets the editor shell paint before live computation.

Do not move the explicit user-command recompute mutation unless doing so is required to avoid
duplicating the endpoint; its notification and invalidations remain editor lifecycle behavior.

`computeSignature` may become a private/exported Cycles helper. Its scientific projection must be
byte-for-byte equivalent so presentation-only edits do not trigger backend computation and
scientific edits do.
