# 111.5 — Existing analyses, Steps and overlap

**Status:** Planned implementation step 5 of 7. [Parent contract](111-virtual-cells.md). Depends on [111.4](111.4-virtual-cell-cycle-metrics.md).

Wire typed subjects into analysis selection, saved plots, sample visibility, workers, usage checks and update notifications.

- Creation and ungrouping never rewrite an analysis that already selected a physical cell or replicate group. In a new or edited analysis the user can explicitly select the whole virtual cell or an original run. The analysis still owns the common sample set. Store a plot’s run choice on that plot or series so choosing B in Steps cannot remove A from a timeline.
- **Steps** offers member runs separately. Each series retains the physical run ID, its own protocol signature and selected programmed indices. Resolve executions using the normal source-local step-block logic. Label each series with its run, use that run’s occurrence numbering, and carry its source provenance. Support A and B as separate series in one Steps plot. Whole-experiment step mapping is outside the pilot.
- Apply the run selection before evaluating the existing protocol safety guard. A virtual sample on another tab cannot block a valid Steps series for A or an unrelated sample. A selected run with multiple files or an unverified protocol gets the same limitation as when opened directly. Scope DCIR, Chargeability and C-rate similarly to eligible individual runs. Their pulse pairing, rate sweeps and reference capacities belong to that run.
- Deduplicate or reject overlap before aggregation using contributing physical runs/sources, including indirect replicate membership. Direct comparison overlays are allowed with clear labels. Never count V and B as two independent replicates. Preserve unrelated group statistics, explicit exclusions and saved series identity.
- On ungroup, reopen saved whole-experiment selections through their retained virtual identity. A Steps series scoped through retired V uses the recorded member source list. A directly selected physical B remains live and can acquire more sources. Keep this scope explicit when both appear in the same analysis. Handle saved and draft plots, thumbnails, cache warmup, source-change notifications and removal previews consistently.

**Acceptance.** Save analyses for A alone, B alone, an unrelated replicate group and V. Include a Steps comparison where step 2 means discharge in A and rest in B. Exercise combine, append to B, ungroup, restart and reopen. Check each Steps quantity, occurrence axis, label and source. Verify V plus B cannot inflate an aggregate; hiding one trace never redefines scientific membership.
