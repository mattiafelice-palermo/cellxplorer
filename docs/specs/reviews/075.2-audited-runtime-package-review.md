## Boundaries

The comparison is an uncompressed local backend inventory, not a measured
compressed-download reduction. Python patch releases can change Tcl data layout.
Old installed leftovers are not recursively pruned. Tests do not claim header
output parity, full portable export, interactive file-picker behavior, NDA,
BioLogic CP/OCV or private-corpus frozen acceptance. Existing comprehensive source
regressions remain intact. Final signed native install/update/data/isolation and
full recovery/CI verification remain mandatory in 075.3.
