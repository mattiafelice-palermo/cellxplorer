**Current**

Resolved in `16c0538e07f9c1b6022fc6e87927d86bf7563df6`.

The implementation now evaluates the selected first-N discharge values with:

```python
valid = first_n[~np.isnan(first_n)]
return float(valid.max()) if len(valid) else float("nan")
```

This reproduces the previous `Series.max(skipna=True)` contract for mixed finite/NaN windows and preserves NaN for empty/all-NaN windows.
