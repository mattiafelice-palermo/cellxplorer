## Findings

### R1 — High: structurally valid corrupted step metadata can silently truncate scientific rows — **Resolved**

Affected files:
- `backend/app/services/cache.py`
- `backend/app/services/stitch.py`
- `tests/test_raw_cache_layout.py`

**Resolution**

The sidecar now carries bounded per-row-group step facts and a detail fingerprint. `_validate_step_detail_index()` reconstructs the expected step-to-group mapping from those facts and rejects any mismatch or stale fingerprint. `load_raw_step_rows()` therefore receives only validated detail metadata; corrupt detail returns `None`, allowing `stitch_raw_steps()` to use the established full-raw fallback rather than returning partial rows.

**Acceptance evidence**

- structurally valid omitted-group corruption regression: implementer-reported PASS;
- valid selective reader still reads implicated groups and preserves expected frame/source metadata in focused coverage: implementer-reported PASS;
- validation uses the cache sidecar/Parquet footer and does not reopen the original source;
- no SQLite migration or `CALC_VERSION` bump.

### R2 — Medium: selective step reads release the raw-layout consistency lock before Parquet access — **Resolved**

Affected files:
- `backend/app/services/cache.py`
- `tests/test_raw_cache_layout.py`

**Resolution**

`load_raw_step_rows()` now holds `_raw_layout_access(wait=False)` continuously across index existence checks, sidecar load/validation, detail-map selection, Parquet row-group decode, exact filtering and result construction. Busy access returns `None` immediately. The publisher/converter uses the same `_raw_layout_io_lock`, so the validated sidecar and active Parquet cannot be replaced by another generation during the selective read.

**Acceptance evidence**

- busy-boundary concurrency regression: implementer-reported PASS;
- valid selective row-group behavior and scientific parity remain covered by the focused/golden suites: implementer-reported PASS;
- existing Time/Capacity cycle-selective behavior and full-raw fallback are untouched by the fix delta.
