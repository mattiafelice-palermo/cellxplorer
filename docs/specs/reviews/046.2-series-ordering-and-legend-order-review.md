## Findings

### R1 — Medium: A pending reorder can overwrite a newly applied palette

**Resolution: RESOLVED in `4224c55710c89cffebb6d538e87674f180569f5e`.**

`applyScratchPalette()` now flushes any pending complete base-style snapshot before calling the parent Palette Apply path, preventing a stale reorder snapshot from landing afterward. It also applies the same palette to `draftBaseStyle`, so a subsequent reorder is composed from the newly applied palette rather than the previous one. The parent update path uses functional `setSpec(...)`, so the two parent mutations compose deterministically. Focused state-composition coverage was added.
