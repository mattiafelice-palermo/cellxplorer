## R1 — Resolved

### Actual Cycles renderer behavior

The previously accepted product fix remains correct.

For aggregate series, `cycleTracesForResult(...)` computes independent primary/CE emission gates. Confidence bands, the primary aggregate trace, and low-n markers are emitted only inside the primary branch. CE is emitted from a separate CE branch, so hiding the primary no longer prevents CE rendering.

For ungrouped cells, the primary trace and source-boundary helper are similarly contained in the primary branch, while CE is emitted independently. Thus CE-only mode does not leak primary-owned helpers.

When both visibility targets are enabled, both branches execute and normal primary + CE output is preserved.

### Direct renderer regression

`frontend/tests/cycleTraceRenderer.test.ts` closes the verification gap by loading the real TSX module through a Vite SSR server and directly calling `cycleTracesForResult(...)`.

The aggregate CE-only case:

- hides `cycles:g7` while leaving aggregate CE visible;
- requires exactly one returned trace;
- requires that trace to use `y2` and be named `LFP CE`;
- asserts no `LFP mean`, `LFP band`, or low-n helper trace is returned.

The same aggregate fixture is used in the both-visible case and does produce `LFP band`, so the band-suppression assertion is non-vacuous and guards primary-helper ownership. The low-n assertion itself is weaker because the fixture uses `n = 2` with `min_n_for_band = 2`, so that specific helper would not be generated even with the primary visible; this is a minor test-quality limitation, not a remaining finding, because the production low-n block is directly nested inside the accepted primary-emission branch and the direct renderer test now covers the original renderer control-flow failure.

The ungrouped-cell CE-only case:

- hides `cycles:c1` while leaving cell CE visible;
- requires exactly one `Cell A CE` trace on `y2`;
- asserts no primary `Cell A` trace and no `Source boundary` helper is returned.

The cell fixture has a real source-position transition from 1 to 2 with finite plotted data, so a source-boundary marker would be generated in a normal primary-visible path; the CE-only assertion therefore meaningfully verifies helper suppression.

The ordinary both-visible aggregate case asserts that `LFP mean`, `LFP band`, and `LFP CE` are all emitted, guarding normal primary + helper + CE behavior.

This is sufficient to close the verification-only R1 finding.
