## Findings

### R1 — P0 — Packaged cleanup helper cannot import its predicate script

**Affected files**

- `src-tauri/nsis-hooks.nsh`
- `src-tauri/kill_installation_processes.ps1`
- `tests/test_app_channels.py`
- `tests/test_frontend_channel.py`
- optionally a focused NSIS/helper contract test if that is the narrowest owner

**Current**

`nsis-hooks.nsh` embeds the predicate file into `$PLUGINSDIR` as:

```text
cellxplorer-installation-process-scope.ps1
```

but the packaged cleanup entry point executes from the same `$PLUGINSDIR` and dot-sources:

```powershell
. (Join-Path $PSScriptRoot "installation_process_scope.ps1")
```

Those basenames do not match. The focused PowerShell probe passes only because it executes against the repository source directory, where `installation_process_scope.ps1` exists under its source filename. In a built NSIS installer the dot-source target is absent, so PowerShell exits with an import/file-not-found failure, `nsExec::ExecToStack` returns non-zero, and the pre-install/pre-uninstall hook aborts before process cleanup or normal file operations.

The current static tests only assert that both filename strings appear somewhere in the hook/helper text; they do not prove that the runtime-extracted basename equals the basename that the helper imports.

**Target**

The NSIS-extracted predicate filename and the helper's dot-source filename must be exactly the same runtime path. Preserve the existing install-root ownership predicate and do not restore shared-name cleanup.

**Acceptance criteria**

- The predicate file extracted into `$PLUGINSDIR` is imported successfully by `kill_installation_processes.ps1` in the packaged layout.
- Add a focused regression assertion that would fail if the NSIS `/oname` basename and the helper's imported basename diverge again; a substring-presence assertion is insufficient.
- Existing install-root boundary, protected-ancestor, BackendOnly, and no-image-name-kill tests remain green.
- Canonical `python scripts\preflight.py` passes after the repair.
- A packaged installer reaches and completes the helper invocation without a missing-script/import error before R2's matrix is accepted.
