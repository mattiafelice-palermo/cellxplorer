# 075.1 review — Native installer helper

Independent read-only design and implementation review completed. Final verdict:
no remaining actionable findings in the revised code. Suites below were run by
the implementing agent, not independently repeated by the reviewer.

## Findings and disposition

- R1 (P1), fixed: preserve Windows ordinal-ignore-case ownership rather than
  Unicode lowercasing. U+0130 and U+0069/U+0307 directories must not collide.
  Native CompareStringOrdinal and explicit negative regressions now enforce it.
- R2 (P2), fixed: prove delayed backend exit and quiet-count reset, not merely
  readiness-file creation. Tests assert launcher/child completion and at least
  800 ms since the delayed observation before cleanup returns.
- R3 (P2), fixed: enforce the single monotonic deadline during ancestry/snapshot
  enumeration and before each termination, not only after an entire batch.
  Targeted injected expiry cases cover snapshot entry and pre-termination guards.
- R4 (P1), found before publication and fixed: legacy Unicode whitespace trimming
  could turn an NBSP-ending installation into its distinct plain-name sibling.
  NSIS rejects ASCII space/dot endings but not NBSP. Remove trimming entirely;
  retain exact separator/extended-prefix normalization and ordinal comparison.
  Unit regressions construct the production prefix, cover both sibling directions
  and preserve EM SPACE. A real NBSP/plain-directory process fixture verifies the
  target exits and the plain sibling survives. Independent re-review accepted
  this specific correction; all 13 tests (seven pure/guard, six native) passed.
  The earlier successful hosted candidate is not publication acceptance for R4;
  full preflight and a fresh committed-candidate rehearsal are required.
  Corrected local canonical preflight passed 4/4, 206 modules, 201.95 seconds.

Additional review improvements: retain unresolved/pending process handles until
signaled; transient Windows image-unmap-before-signal observations cannot count as
quiet and retry only within the original deadline. Never terminate an unverified
image. Verify actual PE RT_MANIFEST asInvoker and GUI subsystem, and restart an
actual CONSOLE-subsystem fixture with no console attached. NSIS hashes the locked
candidate helper against an embedded digest and prepares it before READY/E.

## Acceptance boundaries

No real installation or scientific data was modified. Native tests use dedicated
temporary directories and harmless fixture processes. Targeted deadline probes
do not claim broad kernel-failure or PID-reuse coverage; conservative PID-reuse
timeouts remain possible. Signed hosted install/update/data/isolation and final
recovery tests are required in 075.3. Interactive UAC and real desktop RunAsUser
acceptance remain distinct from GUI-subsystem, argv and hosted admin tests.
