## R1 review — resolved

### Corrected causal model

The previous review correctly challenged the original claim that Plotly's inferred `xaxis.type` / `yaxis.type` writes were themselves the cause of `activePlotDirty`.

The new regression now encodes the correct architecture:

- `plotViewSignature(spec)` is the persisted-view dirty contract;
- the former shallow export figure could expose derived trace/layout objects to Plotly normalization;
- those derived mutations are not linked back to the persisted `AnalysisSpec` and therefore do **not** change `plotViewSignature(spec)`;
- the repaired `exportFigure(...)` deep-clone boundary still prevents renderer writes from mutating caller-owned derived traces/layout;
- changing `presentation.plot_styles.<tab>.export_format` through the UI is a legitimate persistent edit and therefore changes the saved-view signature.

This matches Spec 055.1's locked distinction: changing a stored export preference may dirty the plot, while merely producing a file must not.

### Regression inspected

`frontend/tests/plotExport.test.ts` now:

1. constructs an `AnalysisSpec` and captures `baseline = plotViewSignature(spec)`;
2. simulates the legacy shallow export graph and renderer writes;
3. proves `plotViewSignature(spec) === baseline` and the spec is byte/deep-equal to its pre-export copy;
4. runs the repaired `exportFigure(...)` path and repeats the same invariant;
5. changes the persisted `export_format` preference and proves the signature changes.

Together with the existing test that verifies nested export-figure mutation cannot flow back into source traces/layout/style, this is sufficient to resolve the prior causal-proof concern.

### Code inspection retained

The original implementation remains acceptable:

- `exportFigure(...)` deep-clones traces and nested layout before Plotly sees them;
- export-only width/height/autosize/margin/title remain on the derived export figure;
- preview and shared PNG/SVG/PDF export paths route through the same export boundary;
- no post-export `dirty` or baseline reset exists;
- Cycles, Time/Capacity, and the shared simple-family export paths inherit the same policy;
- no 055.2/055.3 behavior is mixed in.
