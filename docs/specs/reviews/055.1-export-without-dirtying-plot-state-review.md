## R1 — RESOLVED — Signature/root-cause regression

The corrected regression matches the actual saved-plot dirty architecture:

- `plotViewSignature(spec)` is the persisted-view dirty contract;
- the former shallow export graph could expose derived traces/layout to Plotly normalization;
- those derived writes do not alias the persisted `AnalysisSpec` and therefore do not change `plotViewSignature(spec)`;
- the repaired `exportFigure(...)` deep-clone boundary prevents renderer writes from mutating caller-owned derived traces/layout;
- an intentional export-preference change through `presentation.plot_styles.<tab>.export_format` is a legitimate persisted edit and does change the signature.

`frontend/tests/plotExport.test.ts` now captures this distinction directly by proving the legacy derived mutation leaves the saved-view signature and spec unchanged, proving the repaired export figure preserves the same invariant, and separately proving the intentional persisted format change dirties the signature.

Code inspection also confirms:

- no post-export dirty/baseline reset workaround exists;
- export-only width/height/autosize/margin/title changes remain on the derived export figure;
- shared preview and PNG/SVG/PDF paths route through the same export boundary;
- Cycles, Time/Capacity, and shared simple-family export paths inherit the same policy.
