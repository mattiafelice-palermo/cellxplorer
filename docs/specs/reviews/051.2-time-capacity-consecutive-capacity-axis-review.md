### R2 — High — Open — Multi-Cell/sparse refinement can still fail when `req.cycle_start` is absent for one Cell

**Affected files:** `backend/app/routers/analyses.py`, `backend/app/services/analysis_engine.py`, `backend/app/services/time_capacity_workers.py`, `tests/test_analysis_engine.py`

**Current:** The returned implementation fixes the original downsample-origin defect: overview traces now carry exact per-cycle display origins computed before downsampling, and capacity refinement no longer replays the raw prefix. However, the router looks up exactly `req.cycle_start` for every visible Cell and only accepts the request if every visible trace supplies that origin. Consequently, in a multi-Cell analysis where one Cell ends before the requested late range, or where a Cell lacks that exact start cycle but has later cycles in the requested range, that Cell makes `display_origin_capacity_by_cell` incomplete and the entire refinement returns HTTP 409. A valid refinement for the other Cells is therefore blocked.

**Target:** Resolve the capacity refinement origin independently per Cell from that Cell's first actually available cycle within the requested range. A Cell with no rows in the requested range must be allowed to return an empty trace without blocking other Cells. Preserve the exact pre-downsample origin source and bounded indexed/fallback reads; do not reintroduce prefix replay.

**Acceptance criteria:**
- Add a multi-Cell regression where one Cell reaches at least cycle 30 and another ends before cycle 28; refining cycles 28–30 returns the longer Cell at the overview-compatible coordinate and leaves the shorter Cell empty/nonblocking rather than returning 409.
- Add a sparse/missing-start regression where a Cell lacks cycle 28 but has cycle 29/30; use the exact origin of the first available requested cycle and keep coordinates aligned.
- Diagnostics prove neither case replays cycles 1..N solely to obtain display offset.
- Optimized serial/process and analysis-engine fallback behavior remain equivalent for these cases.
