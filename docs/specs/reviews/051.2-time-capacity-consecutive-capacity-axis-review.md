## Findings

### R1 — High — Same-phase cycle/source boundaries can still reset display X

**Affected files:** `backend/app/services/time_capacity_derived.py`, `backend/app/services/analysis_engine.py`, `backend/app/services/time_capacity_workers.py`, `tests/test_time_capacity_display.py`

**Current:** `phase_capacity(...)` resets its scientific carry whenever `(cycle, phase)` changes, but `consecutive_capacity_display(...)` receives only values/phases and starts a new display segment only on phase changes or neutral gaps. A direct charge→charge or discharge→discharge cycle boundary therefore keeps the old segment origin while the input phase capacity can restart, causing a backward display jump. A continued source boundary with the same active phase has the same risk.

**Target:** The display helper must receive enough segment identity to restart its local origin at every scientific phase-capacity reset boundary relevant to display concatenation, while still avoiding artificial splits at same-direction protocol steps. Normal cycle/source boundaries must continue from the prior display endpoint.

**Acceptance criteria:**
- Add an adjacent cycle-1 charge → cycle-2 charge regression with no rest; cycle 2 starts at the previous display endpoint.
- Cover the equivalent same-phase discharge case or prove the generic path.
- Add an ordered multi-source same-phase continuation regression.
- Verify fallback and optimized worker paths produce the same coordinates.

### R2 — High — Refinement origin from the downsampled overview is not coordinate-safe and the fallback can replay large prefixes

**Affected files:** `backend/app/routers/analyses.py`, `backend/app/services/analysis_engine.py`, `backend/app/services/time_capacity_workers.py`, `tests/test_analysis_engine.py`

**Current:** The router derives `display_origin_capacity_by_cell` from the first retained downsampled overview point matching the requested cycle. `_downsample_indices(...)` does not preserve every cycle start, so that retained point can be mid-cycle or the cycle can be absent. A mid-cycle point translates refinement incorrectly. If no origin is found, the engine fallback can expand the refinement window back to the original analysis start, replaying a large cycle prefix merely to reconstruct display X.

**Target:** Derive the exact per-cell requested-cycle display origin from owner-resolved exact/prepared/indexed facts rather than an arbitrary retained overview sample. Keep refinement bounded; late-cycle refinement must not reread/recompute cycle 1..N solely to reconstruct the display coordinate.

**Acceptance criteria:**
- Force an actually downsampled overview where the first retained point of a requested cycle is not the raw cycle start; refinement aligns with the exact canonical/overview coordinate.
- Cover a requested cycle that has no retained overview point; refinement remains coordinate-correct and bounded.
- Add diagnostics/assertions proving the selected/refined read range does not replay the full preceding cycle prefix.
- Verify serial/process/fallback parity.

### R3 — Medium — Mandatory 051.2 regression matrix is incomplete

**Affected files:** `tests/test_time_capacity_display.py`, `tests/test_analysis_engine.py`, `tests/test_time_capacity_workers.py`, relevant Neware/BioLogic fixture regression tests

**Current:** The new tests cover several basic segment shapes and cache versioning, but do not explicitly cover ordered multi-source continuation, compact/non-compact equivalence before downsampling, serial worker/process/fallback agreement, Neware fixture regression, or BioLogic reconstructed-cycle fixture regression. The test labeled as a cycle transition does not model a same-phase cycle reset.

**Target:** Add the focused regressions required by Spec 051.2 so the generic Neware/BioLogic failure mode and owner-path parity are executable guards rather than browser-only evidence.

**Acceptance criteria:**
- Add the missing mandatory cases from the 051.2 test matrix.
- The boundary-focused tests fail against the pre-fix behavior where applicable.
- Keep browser acceptance, but do not use it as the only regression guard for Neware/BioLogic.
