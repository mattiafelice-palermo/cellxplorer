## Scope reviewed

- Final import previews are explicit per-source idle/loading/ready/error state.
- Only the active separate-cell source or continued-cell preview source requests capacity data.
- Preview requests reuse the inspected content hash when size and lossless `mtime_ns` match, rehash
  when the fingerprint differs, and return structured `409 source_changed` when content differs.
- Preview results are cached in the open frontend session by content hash and late responses are
  ignored when a staged source is removed or replaced.
- Registration commits relational Cell data first and reports the existing background cache job ID,
  count, and status. Cache failures preserve registered Cells and mark affected source files
  errored.
