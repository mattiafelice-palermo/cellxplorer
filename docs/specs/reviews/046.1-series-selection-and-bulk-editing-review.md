- Branch scope for this checkpoint is limited to workflow/review files plus the expected 046.1 frontend files; no 046.2 ordering or 046.3 detached-legend work was mixed in.
- `ALL_SERIES_KEY` remains distinct from concrete row selection.
- Concrete selection supports plain/Ctrl/Cmd/Shift logic, row checkboxes, and quantity tri-state selection in the Series panel.
- Deliberate selection routes through `selectConcreteKeys(...)`, which returns the right panel to the Series tab.
- Preview-eye state remains local `previewHidden`; persisted legend membership remains `show_in_legend`.
- Multi-selection values are derived from effective `resolvedByKey` styles rather than raw override objects.
- Bulk editing writes through the existing explicit override layer via the pure `applySeriesOverridePatch(...)` helper.
- `Reset selected` removes explicit overrides only for the selected concrete keys.
- The Palettes editor contents are unchanged; the implementation adds only a compact `Global` scope cue to the tab label.
- The pure bulk helper preserves unrelated fields, selected-key scope, fall-through/null behavior, and empty-entry pruning.
- Row keyboard selection is isolated from descendant checkbox/preview-eye keyboard activation.
- Bulk colour editing is disabled only when a selected secondary will actually inherit colour from a present primary; orphan secondaries retain independent colour editing.
- Descriptor pruning keeps `activeKey` coherent with a sole surviving selection.
- Empty concrete selection is reported separately from an actually empty descriptor list.
