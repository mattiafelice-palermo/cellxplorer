## Decision evidence for follow-up work

050.5 supports two independent later optimization scopes; neither was implemented here:

1. **Normal Time/Capacity prepared-derived-row optimization.** Broad and multi-Cell compact requests are dominated by repeated exact `_phase_capacity()` reconstruction. Compact Time-axis Voltage/Current also performs phase-capacity/specific/areal work that is not consumed by that view. The first follow-up should therefore preserve exact scientific rows while avoiding demonstrably unused work and preparing/reusing Cell/source-chain-scoped invariant derived arrays before any multiresolution overview is considered.
2. **Derivative-specific optimization.** dQ/dV has a different cost structure: the backend is dominated by repeated post-gradient per-segment processing, while the frontend creates hundreds of Plotly traces for broad selections. This scope should remain separate from normal prepared-row optimization because its scientific and rendering acceptance criteria differ.
