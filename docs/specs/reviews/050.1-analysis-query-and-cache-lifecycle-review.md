## Findings

### R1 — High: compatible placeholder data can still be exported as the current plot

Status: **Resolved in round 2 (`a7e84d7`)**

Affected files:
- `frontend/src/features/analyses/editor/families/time-capacity/TimeCapacityPlotCard.tsx`
- `frontend/src/features/analyses/editor/plotting/PlotHeader.tsx`
- `frontend/src/features/analyses/editor/policies/timeCapacityQueryPolicy.ts`
- `frontend/tests/timeCapacityQueryPolicy.test.ts`

**Current (round 1)**

050.1 intentionally kept a previous Time/Capacity result visible while a compatible range/density request was fetching. The card correctly dimmed the plot while `timeResult.isFetching`, but plot export remained enabled and serialized the retained placeholder directly.

**Target**

A retained Time/Capacity placeholder must never be exportable as though it were the resolved current request. Valid export behavior for an actually current result must remain intact, and the separate full-resolution data-export contract must not be weakened.

**Resolution**

`timeCapacityPlotExportReady()` now requires `!timeResult.isPlaceholderData`, a current valid result, an available voltage channel, and non-empty traces. That readiness gates the plot-export controls, export preview, and the export function itself. `canExport` continues to govern the separate full-resolution data-export path, which still performs its own current-request identity validation.

**Acceptance criteria**

- **PASS by code inspection + focused implementer tests:** placeholder PNG/SVG/PDF export is unavailable while compatible placeholder data is displayed.
- **PASS by code inspection:** plot export becomes available again only for non-placeholder current results with valid traces.
- **PASS:** incompatible changes still return no placeholder through the separate compatibility policy.
- **PASS:** focused regression coverage was added for export readiness and component/header wiring.
- **PASS (implementer-reported):** focused tests, TypeScript check, `git diff --check`, and canonical preflight passed before handoff.
