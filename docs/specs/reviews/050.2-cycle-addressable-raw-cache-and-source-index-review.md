## Findings

### R1 — Medium: scientific cleanup can still delete a checksum directory after layout conversion has acquired cleanup protection

Affected files:
- `backend/app/services/cache_maintenance.py`
- `backend/app/services/cache.py`
- focused cache-maintenance/raw-layout tests

**Round-1 Current**

050.2 added `protect_hash_from_cleanup()` around raw-layout conversion, but `cleanup_eligible_scientific()` and `enforce_scientific_limit()` only took an earlier `pending_hashes()` snapshot before later deleting directly, while `cleanup_offender(kind="scientific", ...)` bypassed live protection entirely. A converter could acquire protection after candidate discovery and still have its checksum directory removed mid-conversion.

**Target**

Every scientific checksum-directory deletion path must honor the live pending/protected boundary immediately before deletion, while preserving existing offline-source and explicit forced-cleanup semantics.

**Acceptance criteria**

- Automatic eligible cleanup waits for live conversion protection.
- Budget enforcement revalidates/waits at deletion time even if protection starts after candidate discovery.
- Explicit scientific-offender cleanup uses the same boundary, including force mode.
- Focused concurrency coverage proves all cleanup paths cannot delete until protection is released.
- Existing offline-source preservation, sidecar accounting and post-protection cleanup semantics remain unchanged.

**Round-2 resolution — resolved in `7b70b4a`**

Resolved. `_cleanup_delete_boundary()` now serializes scientific deletion with the same pending/protected lock used by conversion. `cache.remove_hash_cache()` owns that boundary, and all three scientific maintenance deletion paths call it. The new test explicitly models the round-1 TOCTOU case by making the maintenance snapshot report no pending hashes after protection is already live; automatic cleanup, budget enforcement, and forced offender cleanup remain blocked while the protected checksum directory remains present, then complete only after release. No scientific identity/version behavior changed.
