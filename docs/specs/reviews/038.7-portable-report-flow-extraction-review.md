## Endpoint and payload equivalence

The extracted module preserves the existing portable calls and request shapes:

- `GET /api/analyses/{id}/portable-estimate` with query key `["portable-analysis-estimate", analysisId]`, modal-gated enablement, and 30-second stale time;
- `POST /api/analyses/{id}/portable-source-preflight` with the existing empty request object;
- `POST /api/analyses/{id}/portable-source-update` with changed-source IDs plus expected size/mtime guards;
- `POST /api/analyses/{id}/portable-export` with `include_original_files` and canonical `views` snapshots.

The 409 export conflict path still re-runs source preflight, and the source-update path keeps the same affected-analysis artifact/query removals plus broad library/analysis invalidations before rebuilding the selected plots.

## Plot and source behavior

`PortableReportFlow` consumes `buildPortablePlotSnapshots` from the 038.6 artifact owner rather than compiling family figures itself. The page no longer contains portable snapshot orchestration. Existing saved-plot ordering, in-memory artifact reuse, canonical family builders, hidden-series styling, SVG fallback generation, and progress accounting therefore remain on the established artifact path.

The existing source-compatibility policy is preserved per selected view. Changed, unavailable, changing, and read-error sources remain explicit blockers when originals are requested; automatic adoption remains limited to stable changed sources with expected size/mtime evidence. Continuing without originals remains an explicit user action rather than a silent fallback.

## Editor integration and share behavior

The public component boundary is narrow and typed: analysis identity/title/spec, analysis/cell/group summaries needed for source compatibility, the existing compatibility-pending flag, `normalizeSpec`, and the editor-owned persistence callback. The module does not import the route page or an editor state object and does not introduce global/context state.

Before packaging, the flow still obtains the stable editor spec through the supplied persistence callback and performs the existing analysis PUT. The native share path remains deliberately invoked from the explicit button click to preserve the WebView user gesture. Unsupported Windows sharing still falls back to saving the prepared HTML; cancellation remains non-destructive.

## Scope and backend ownership
