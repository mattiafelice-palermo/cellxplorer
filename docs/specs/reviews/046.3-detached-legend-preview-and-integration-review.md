## Confirmed

- 046.3 is a focused final-child implementation after review-clean 046.2; no unrelated scientific/backend/schema work is mixed in.
- The main scientific preview remains fixed-size and explicitly legend-free.
- The detached legend is built from an unhidden family-specific Plotly preview, so the preview-only eye does not remove legend entries.
- `buildLegendPreview(...)` filters `showlegend: false` helper/shadow traces and strips scientific positional/customdata payloads.
- Effective name, line, marker, mode, opacity, legend group and legend rank metadata are copied from the actual preview traces rather than rebuilt from descriptors.
- Local base-style/order changes and scratch-palette state are included in the preview overlay before the parent debounce commits them.
- Legend traces now remain in Plotly's normal visual state while carrying empty positional arrays, so the detached legend does not inherit the automatic `legendonly` fade and still retains no scientific curves/data.
- The detached Plotly config keeps the modebar disabled but no longer sets `staticPlot`, allowing Plotly 2.35.3's bounded legend scrollbar to operate. Item and double-click legend mutation paths remain disabled.
- The implementation no longer relies on unsupported Plotly 2.35.3 `legend.maxheight` behavior.
- 046.2 already propagates `show_in_legend` and deterministic `legendrank` through the supported Cycles, Time/Capacity, Steps, DCIR, Chargeability and Rate capability builders used by live/saved/export paths.
- Legend trace positional data is stripped before the detached Plotly instance, avoiding retention of large scientific arrays.

## Findings

### R1 — Medium: `legendonly` systematically fades every detached legend entry

**Resolution: RESOLVED in `e4f8c5a457b6e3c9d3731dedf8afdab9c5e24342`.**

Legend preview traces no longer set `visible: "legendonly"`. They keep normal Plotly visibility while x/y (and z when present) are replaced with empty arrays, preserving effective symbol/text styling without retaining or drawing scientific data. Focused regression coverage now asserts that the transformed trace does not carry a `visible` override and still strips positional/customdata payloads.

### R2 — Medium: Large detached legends are clipped with no usable scrollbar in the bundled Plotly version

**Resolution: RESOLVED in `e4f8c5a457b6e3c9d3731dedf8afdab9c5e24342`.**

The detached Plotly config no longer uses `staticPlot`, so Plotly 2.35.3 can expose its internal bounded legend scrollbar. The unsupported `legend.maxheight` property was removed. The modebar remains disabled and `itemclick`/`itemdoubleclick` remain false, keeping the detached legend passive. Focused coverage asserts the absence of both `staticPlot` and `maxheight` assumptions.
