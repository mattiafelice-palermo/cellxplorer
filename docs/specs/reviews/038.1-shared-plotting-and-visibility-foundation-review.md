## Follow-ups

### R1 — High: CSV export no longer writes the UTF-8 BOM

**Affected file**

- `frontend/src/features/analyses/editor/plotting/plotExport.ts`

**Current**

The pre-refactor `buildDelimitedText()` in `AnalysisPage.tsx` prepended the actual Unicode BOM character:

```ts
return "﻿" + lines.join("\r\n");
```

During extraction, that character was mojibake-converted to the three visible Unicode characters `ï»¿`:

```ts
return "ï»¿" + lines.join("\r\n");
```

Those strings are not byte-equivalent. When the new string is UTF-8 encoded into the CSV Blob it begins with the UTF-8 bytes for the visible text `ï»¿`, not the required BOM bytes `EF BB BF`. This violates the child requirement that CSV export behavior remain byte/structure compatible and can leave `ï»¿` in the first header while removing Excel's intended UTF-8 detection hint.

The same extraction also mojibake-converted several em dashes in comments in `plotExport.ts`, `plotLayout.ts`, and `plotRuntime.ts`; those comment changes are non-functional but confirm the encoding transformation that caused the active-string regression.

**Target**

Restore the exact CSV prefix semantics from `main`. Prefer an unambiguous source representation such as `"\uFEFF"` so the intended byte-order mark cannot be damaged by another text-encoding round trip. Do not change delimiter, decimal, precision, column ordering, filenames, or any other export behavior.

Add focused regression coverage at the smallest practical pure-helper boundary proving that generated CSV text starts with U+FEFF / UTF-8 `EF BB BF` and does not start with the visible characters `ï»¿`.

**Acceptance criteria**

- CSV output begins with one U+FEFF BOM and therefore UTF-8 bytes `EF BB BF`.
- The first visible CSV header does not contain `ï»¿`.
- Existing delimiter, decimal-separator, precision, provenance-column, and column-order behavior is unchanged.
- A focused regression test fails against reviewed implementation `e8ee40ff...` and passes after the fix.
- TypeScript/build verification required by 038.1 still passes.
