## Assessment

The core scientific contract is implemented correctly. Cycle and raw stitching share one mapping
path, observed source-local cycle labels are mapped densely without inventing missing cycles,
source provenance is retained, and a missing ordered cache prevents later sources from being
compacted across the gap. The `CALC_VERSION` bump is justified.

One invalid-input path still violates the required fail-closed behavior: non-finite numeric cycle
labels can raise during integer conversion instead of being diagnosed as invalid source data.

## Confirmed correct by code reading

- `stitch_cycles` and `stitch_raw` use the same `_stitch_ordered` and dense-cycle helpers.
- Missing local labels are not inferred from `max - min + 1`.
- Stitched rows retain `source_cycle`, `cycle`, `segment`, and `source_hash`.
- Segment metadata contains local/global cycle ranges, observed cycle count, and
  `incomplete_boundary_unknown: true`.
- A missing or invalid ordered source blocks mapping of later sources and records original positions.
- Raw rows are not globally sorted by timestamp; `record_index` is used only within each source.
- Single-source contiguous cycle numbering remains unchanged.
- No private Neware source file was committed.

## Follow-up tasks

### R1 — Medium: non-finite cycle labels can raise instead of failing closed

**Affected files**

- `backend/app/services/stitch.py`
- `tests/test_stitch.py`

**Current**

`observed_local_cycles` converts values with `pandas.to_numeric`, checks whether they are close to
rounded integers, and then calls `int(value)`. Positive or negative infinity is numeric and can pass
the rounding comparison, but `int(float("inf"))` raises `OverflowError`.

The specification requires invalid cycle values to be diagnosed and the ordered stitch to fail
closed. A malformed cache must not crash cycle or raw analysis computation.

**Target**

Validate that every converted cycle label is finite before rounding or integer conversion. Return a
stable validation error such as `non-finite cycle values` through the existing error-list contract.
Do not coerce infinity to another label and do not append any rows from the invalid source.

Keep the existing behavior for:

- finite integer-valued floats;
- finite non-integer values, which remain invalid;
- strings that cannot be converted;
- all-null cycle columns;
- a later source after the invalid source, which remains skipped.

**Acceptance criteria**

- `+inf` and `-inf` return an explicit validation error from `observed_local_cycles`.
- `stitch_cycles` marks the source position missing/incomplete and does not raise.
- `stitch_raw` follows the same fail-closed behavior.
- A later available source is listed in `skipped_segments` and is not compacted into the result.
- Existing dense-mapping and single-source tests remain unchanged and pass.
