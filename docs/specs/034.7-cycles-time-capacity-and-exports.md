# 034.7 — Cycles, time/capacity, and exports for continued Cells

**Status:** Plan
**Parent:** [034 — Multi-source cell continuations](034-multi-source-cell-continuations.md)
**Depends on:** 034.1, 034.3
**Scope:** Make the two supported analysis families fully source-aware end to end.

## Existing anchors

- `backend/app/services/analysis_engine.py`
  - `cell_ordered_hashes`
  - cycle computation using `stitch_cycles`
  - `compute_time_capacity` using the raw stitch and `_continuous_time`
- `backend/app/routers/analyses.py`
  - `/api/analyses/{id}/compute` for Cycles
  - `/api/analyses/{id}/time-capacity`
  - result/artifact/thumbnail cache routes
- `frontend/src/pages/AnalysisPage.tsx`
  - cycle and time/capacity Plotly builders
  - `tracesToColumns` and the common image/CSV/Excel export pipeline
- Cell/library summaries derive cycle totals from source summaries and must agree with the stitched
  observed-cycle count.

## Backend result contract

For every supported result from a multi-source Cell:

- global displayed `cycle` is the dense value from 034.1;
- source-local `source_cycle` is retained;
- every returned point/row carries or can be unambiguously joined to `segment` and `source_hash`;
- source descriptors enrich segments with source file ID, filename, position, local/global cycle
  ranges, start/end timestamp when known, and tracked-tail state;
- a missing ordered source cache returns no scientifically continuous series for that Cell and an
  explicit `continuation_source_missing` badge/error;
- mixed selections cannot silently omit the failed continued Cell.

Do not key source identity by filename alone.

## Cycles tab

- Plot global cycles in continuation order.
- Keep incomplete boundary cycles as ordinary points.
- Add subtle source-boundary markers at the first global cycle of each source after the first when
  a Cell has multiple sources.
- Markers use the plot style system, appear in saved figures/thumbnails/image exports, and do not
  create noisy legend entries. Hover/annotation identifies the new filename and global/local
  start.
- Existing cycle filters, reindex-remaining-cycles behavior, replicate aggregation, visibility,
  styles, saved plots, and exports continue to work.

For replicate aggregation, align on global cycle number within each Cell after its own stitching.
Do not align by source-local cycle.

## Time / capacity tab

- Concatenate source rows in scientific order.
- `_continuous_time` remains cycling elapsed time and excludes downtime between files.
- Reset-sensitive counters (time, charge/discharge capacity) preserve existing per-source/step
  behavior; do not add raw counters across a reset unless the selected plot quantity already
  specifies cumulative behavior.
- Add source-boundary markers at the first plotted elapsed-time point of each later source.
- Explain in plot hover/help that elapsed time excludes shutdown gaps.
- Cycle selection/filtering uses global cycle; source-local cycle remains available in hover/export.

## CSV and Excel

The common export must add, where applicable:

- Cell / series label
- Global cycle
- Source-local cycle
- Source position
- Source filename
- Source hash
- Existing x/y quantity columns and units

Equal-length Plotly trace column export may need an explicit provenance column path rather than
only `tracesToColumns`. Keep current precision modes and workbook behavior. Do not expose absolute
source paths in portable/scientific exports.

Single-source exports remain backward-readable; extra provenance columns may be present but must be
documented and stable.

## Library summary consistency

Review list/tree aggregation in `backend/app/routers/library.py`. `total_cycles` for a continued
Cell equals the sum of distinct observed cycles in each successfully summarized source. It must
not use local maximum labels or double-count invented gaps. Pending/error sources preserve
existing status semantics rather than showing a misleading complete total.

## Cache implications

- Ordered hashes already participate in result keys/provenance. Prove reorder changes the key and
  attach/detach cannot load old results.
- Plot artifacts and thumbnails must be regenerated from the same boundary-aware final figure.
- If the response/export schema changes persisted artifacts, update the relevant artifact/result
  format version or cache key; do not rely only on UI code.

## Acceptance

- Two sources with restarted local cycles display one dense global sequence.
- Reorder deterministically changes global mapping, markers, exports, and cache key.
- Default time excludes interruption downtime.
- Missing source cache produces an explicit non-partial state.
- Boundary markers are subtle, source-aware, and identical in live/saved/thumbnail/image output.
- CSV/Excel exposes both global and local provenance without absolute paths.
- Multi-Cell and replicate series remain supported.
- Existing single-source Cycles and time/capacity golden results do not regress except for approved
  additive schema/provenance fields.
