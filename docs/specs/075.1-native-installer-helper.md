## Current owners

`src-tauri/cellxplorer-installer.nsi` restarts through RunAsUser/PowerShell with
opaque hex-encoded JSON argv. `src-tauri/nsis-hooks.nsh` extracts PowerShell
cleanup scripts; `kill_installation_processes.ps1` repeatedly enumerates WMI,
protects ancestors and requires five quiet samples at 200 ms within ten seconds.

## Change

Introduce a small independently built Windows GUI-subsystem helper. Restart only
its sibling `cellxplorer.exe` through the unchanged RunAsUser boundary; decode
bounded hex JSON string argv without shell interpretation. Use ordinary Windows
argument quoting, reject NUL/malformed input, and never accept an executable path
from argv. Remove PowerShell from the production restart/cleanup launches.

Cleanup uses native process snapshots and queried executable paths, preserving
case-insensitive directory-separator ownership, complete ancestor protection,
backend-only selection, repeated late-child detection, five 200-ms quiet samples,
the ten-second monotonic deadline and fail-closed nonzero exit. Only terminate
processes confirmed inside the exact installation through their live handles;
do not kill unrelated descendants merely because they share a parent.

Extract the new helper from the candidate installer before any existing-file
mutation; never trust a helper from the old installation. Retain recovery/E/UAC
authorization ordering and the current exact-payload test matrix.

## Verification

Pure boundary/argv tests, real disposable process/late-child/ancestor/isolation
fixtures, Windows argv roundtrip and GUI-subsystem checks. Preserve regression
coverage of the previous PowerShell contracts, adapting assertions to the new
owner rather than retaining obsolete implementation-string checks. Build and
test the helper independently of the Tauri dependency graph; compile all three
NSIS products and execute existing recovery/policy fixtures. Record actual
shutdown timings and acceptance limitations in the review.
